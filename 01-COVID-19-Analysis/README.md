# COVID-19 Data Analysis

## 📊 Project Overview
This project performs comprehensive exploratory data analysis (EDA) on COVID-19 datasets to understand the spread, impact, and trends of the pandemic across different regions and time periods.

## 🎯 Objectives
- Analyze COVID-19 case trends over time
- Visualize geographical distribution of cases
- Study mortality rates and recovery patterns
- Identify patterns and correlations in the data
- Generate insights for public health understanding

## 📁 Dataset
- **Source**: COVID-19 public datasets
- **Format**: CSV files with time-series data
- **Features**: Cases, deaths, recoveries, dates, geographical information

## 🛠️ Technologies Used
- **Python**: Core programming language
- **Pandas**: Data manipulation and analysis
- **NumPy**: Numerical computing
- **Matplotlib**: Data visualization
- **Seaborn**: Statistical data visualization
- **Jupyter Notebook**: Interactive development environment

## 📈 Analysis Includes
1. **Time Series Analysis**: Daily, weekly, and monthly trends
2. **Geographical Analysis**: Regional spread patterns
3. **Statistical Analysis**: Correlation between variables
4. **Visualization**: Interactive charts and plots
5. **Trend Identification**: Growth rates and patterns

## 🚀 Getting Started
1. Open `covid-19.ipynb` in Jupyter Notebook or VS Code
2. Install required dependencies: `pip install pandas numpy matplotlib seaborn`
3. Run cells sequentially to reproduce the analysis
4. Modify parameters as needed for custom analysis

## 📊 Key Findings
- Detailed insights available in the notebook
- Visualizations showing pandemic progression
- Regional analysis highlighting hotspots
- Statistical correlations between variables
