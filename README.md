## 🚀 Getting Started

### **Prerequisites**
```bash
# Install required Python packages
pip install pandas numpy matplotlib seaborn scikit-learn plotly jupyter

# For geospatial analysis
pip install geopandas folium

# For financial analysis
pip install yfinance pandas-datareader
```

### **Running the Projects**
1. Clone this repository
2. Navigate to any project directory
3. Open the Jupyter notebook in your preferred environment
4. Install project-specific dependencies as listed in each README
5. Run cells sequentially to reproduce the analysis
